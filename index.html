Pensado para estudantes e jovens que estão começando a lidar com dinheiro e querem mais clareza do que uma planilha oferece.

Dashboard

Saldo, receitas, despesas e resultado do período, com gráficos que se atualizam a cada movimentação.

Movimentações

Cadastre, edite e exclua. Pesquise por descrição, filtre por tipo, categoria e período e ordene por data ou valor.

Categorias

14 categorias prontas e quantas você quiser criar, com cor e ícone. Uma categoria em uso não pode ser apagada.

Relatórios

Média mensal de gastos, categoria que mais consome, percentual da renda comprometido e variação em relação ao mês anterior.

Metas financeiras

Defina quanto quer juntar e até quando. O sistema mostra o progresso e quanto guardar por mês. Metas não mexem no saldo.

Educação financeira

Conceitos, regra 50-30-20 e reserva de emergência, calculados com os seus próprios gastos.

Código organizado em camadas

Cada parte tem uma responsabilidade. Isso facilita testar, corrigir e evoluir o sistema.

InterfaceCustomTkinter: telas, formulários, menu lateral e gráficos integrados.
ServiçosValidação das entradas e regras de negócio, como bloquear a exclusão de categorias em uso.

Saldo calculado

O saldo nunca é guardado. Ele é a soma das receitas menos a das despesas, recalculada do banco a cada consulta.

Dinheiro exato

Os valores ficam em centavos inteiros e usam Decimal no Python, sem os erros de arredondamento do ponto flutuante.

Dados protegidos

Consultas parametrizadas evitam SQL Injection, e as regras do banco impedem valores negativos e tipos incompatíveis.

Instale e teste em poucos minutos

Você precisa do Python 3.10 ou mais novo, instalado a partir de python.org.

  1. Baixe o projeto

    No repositório, clique em Code e depois em Download ZIP. Extraia e abra o PowerShell dentro da pasta que contém o arquivo main.py.

  2. Instale as dependências

    python -m pip install -r requirements.txt

  3. Abra com dados de exemplo

    python main.py --demo

    Para usar com seus próprios dados, rode apenas python main.py.

  4. Confira os testes (opcional)

    python -m unittest discover -s tests -v

Deu erro?

“No such file: requirements.txt”: entre na pasta de dentro com cd MoneyTrack.

“python não é reconhecido”: tente py main.py.

Erro com tkinter: reinstale o Python marcando a opção tcl/tk and IDLE.
